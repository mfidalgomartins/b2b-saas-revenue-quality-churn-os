# Executive dashboard

This folder contains the standalone HTML dashboard published by the pipeline.
It embeds its data and visual assets, so it can be opened without a server.

Primary file: `revenue-quality-command-center.html`

Design brief, audit findings and rationale: [`DESIGN_AUDIT.md`](DESIGN_AUDIT.md)

Redirect entrypoints:
- `../../index.html`
- `../../docs/index.html`

Primary access (GitHub Pages):
https://mfidalgomartins.github.io/b2b-saas-revenue-quality-churn-os/

Alternative access: open `revenue-quality-command-center.html` locally.

Note: opening the `.html` file directly on GitHub shows source code, not the interactive dashboard view.
